# Дневник заданий

Готовый проект сайта-трекера домашних заданий: предметы, задания с
дедлайнами и статусами, избранное, вложения (ссылки/фото), поиск,
тёмная тема. Данные хранятся в Firebase Firestore и доступны всем,
кто открыл одну и ту же ссылку с сайтом.

## 1. Установить зависимости

Нужен установленный [Node.js](https://nodejs.org) (версия 18 или новее).

```bash
npm install
```

## 2. Подключить Firebase

1. Зайдите на https://console.firebase.google.com и нажмите **Add project**.
2. Внутри проекта откройте **Build → Firestore Database** → **Create database**
   → выберите режим **test mode** (для начала, потом можно ужесточить правила).
3. На главной странице проекта нажмите значок **`</>`** (Web app), дайте
   приложению имя и скопируйте объект `firebaseConfig`.
4. Откройте файл `src/firebase.js` и вставьте туда свои значения вместо
   `"ВАШ_API_KEY"` и остальных заглушек.

## 3. Запустить локально

```bash
npm run dev
```

Откроется адрес вида `http://localhost:5173`. Первый раз, когда вы
откроете сайт, в адресную строку допишется `?group=...` — это и есть
код вашего общего списка. Все, кому вы отправите ссылку целиком
(вместе с `?group=...`), увидят те же предметы и задания.

## 4. Загрузить код на GitHub

```bash
git init
git add .
git commit -m "первая версия"
git branch -M main
git remote add origin https://github.com/ВАШ-ЛОГИН/homework-tracker.git
git push -u origin main
```

(Репозиторий `homework-tracker` нужно заранее создать на github.com,
сделав его **Public**.)

## 5. Опубликовать на GitHub Pages

1. Проверьте, что в `package.json` в поле `"homepage"` указан ваш логин:
   `https://ВАШ-ЛОГИН.github.io/homework-tracker`.
2. Проверьте, что в `vite.config.js` в поле `base` указано то же самое
   имя репозитория: `/homework-tracker/`.
3. Выполните:

```bash
npm run deploy
```

Через минуту-две сайт будет доступен по адресу из `homepage`.

## 6. Поделиться с одноклассниками

Скопируйте ссылку из адресной строки (или нажмите кнопку
«Скопировать ссылку доступа» в самом приложении) и отправьте её
тем, кто должен видеть тот же список заданий. Каждый, кто откроёт
именно эту ссылку — с одинаковым `?group=...` — увидит и сможет
редактировать общие данные.

Если хотите несколько независимых списков (например, для разных
классов) — просто откройте сайт без `?group=` в адресе ещё раз в
новой вкладке или сотрите его вручную: сгенерируется новый код.

## Безопасность (по желанию)

Режим **test mode** в Firestore открыт для чтения и записи всем, у
кого есть ключи проекта. Для учебного личного проекта это обычно
не критично, но если захотите ограничить доступ — в консоли Firebase
откройте **Firestore Database → Rules** и настройте правила, например,
разрешив запись только в документы, ID которых длиннее случайного
минимума (что уже усложняет подбор), либо добавьте Firebase
Authentication для входа по email.
